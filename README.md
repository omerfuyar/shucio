# Shucio
Shucio (SHU Console Input Output) is a portable, cross platform terminal manager library.

It uses the [SHU](https://github.com/omerfuyar/shu) system. By defining `SHU`, you can tell the library where to find `shu.h`.

Goal is to get instant user input (like ncurses) from any console in Windows, Linux and MacOS with additional features. Plus, I am not planning to add any windows or lists or anything you get from ncurses.
